# Real plugin corpus

A maintained corpus of published Keypirinha packages tested against the Legacy
Compatibility Layer (spec 27.4).

Packages are *not* vendored here. `corpus.toml` records the source, pinned
version, licence and observed classification:

`works-unchanged`, `works-with-configuration-changes`,
`works-with-minimal-source-changes`, `windows-only-but-compatible`,
`blocked-missing-apis`, `blocked-python-version`, `blocked-undocumented-behaviour`,
`works-only-under-legacy-optimized`, `requires-legacy-strict`.
